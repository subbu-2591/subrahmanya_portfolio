# Subrahmanya Gouda Portfolio

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Customize

- Put your resume at `public/resume.pdf`.
- Add your profile photo to `public/profile.jpg` if you want to use one.
- Update LinkedIn, email and GitHub links in `src/main.jsx`.
- Update project descriptions and demo URLs.

## Build

```bash
npm run build
```
